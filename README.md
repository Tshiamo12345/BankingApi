# BankingApi
A Restful Banking / ATM API built with Java and Spring boot.
simulates real banking operations: create accounts, deposit , with, transfer money, and track transaction history.

##features 
-create bank account 
-deposit money 
-withdraw money(with insufficient funds check)
-transfer money between accounts
-view account balanc
-view transaction history 

## Tech Stack 
-Java 21
-Spring boot 
-Spring data JPA 
-Lomback
-Maven 
-PostMan for testing
